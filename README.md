### Инструкции

Проект маркетплейса из четырёх микросервисов.

Материалы для первого знакомства и локального демонстрационного запуска находятся в папке [`demo`](demo/README.md): Docker Compose, скрипты запуска для Linux, macOS и Windows, документация и примеры API-запросов.

Материалы для настройки окружения и автоматизации создания проекта находятся в папке [`scaffold`](scaffold/readme.md): инструкция по установке JDK и работе с Gradle, скрипты для Linux, macOS и Windows, шаблоны микросервисов и общих библиотек.
